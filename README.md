# unimib-poster-template
A template for PhD Day posters at the University of Milano-Bicocca, Department of Informatics, Systems and Communication (DISCo).


## Quick Start
Select this template from the Typst Universe and edit the main.typ file. If you add some references to the `ref.bib` file, they will automatically be included in the correct section (if cited with `@`).



### Fonts
If you want the official fonts for the poster ("Arial" and "Courier New"), you need to upload the .ttf files to the `/fonts` folder. The template will automatically use them if available.
